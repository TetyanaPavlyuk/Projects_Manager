# Projects_Manager
* Проєкт створено з використанням мови програмування python та, безпосередньо, Django ORM.
* Реалізовано моделі: користувачів (Users), проєктів (Project) та відгуків (Feedback).
* З застосуванням міграцій створено базу даних sqlite3 із відповідними таблицями.
* За допомогою представлень реалізовано можливість створення проєктів, додавання та видалення відгуків до проєктів, перегляд списку проєктів та деталей кожного проєкту із списком відгуків.
* З використанням анотації реалізовано підрахунок середнього значення рейтингу для кожного проєкту на основі усіх відгуків.

Коротка структура проєкту:
1. Структурна схема - project_manager_diagram.drawio
2. Моделі - projects/models.py
2. Представлення - projects/views.py
3. Ендпоінти - projects_manager/urls.py
4. Налаштування - projects_manager/settings.py
5. Шаблони - templates/
6. Код для завантаження даних з файлів формату csv в базу даних - db_upload.py
